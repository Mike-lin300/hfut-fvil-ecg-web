# fvil-ec-guide · 飞行器创新实验室电控组 新生导学站

> 合肥工业大学 飞行器创新实验室（电控组）招生季使用的**新生导学与 C 语言培训站点**。
> 目前是一个**纯静态 HTML 文件集**（无后端、无外部依赖、无 CDN），同时也是实验室后续更多网站（官网 / 资料站等）的**雏形与组成单元**。

---

## 这是什么

每年招新后，电控组需要给零基础新生做 C 语言导学培训。本项目把整套培训材料做成了一个可以**双击打开、离线使用**的静态网站：

- **内容**：8 篇导学案（认识 → 计算 → 判断 → 循环 → 数组 → 函数 → 指针 → 结构体）+ 1 篇选读附加材料（状态机等进阶技巧）+ 2 次作业 + 2 篇附录（Windows CMD 常用指令、实验室真实飞控主控代码阅读）。
- **形式**：所有正文以 Markdown 编写（唯一真源），由自研零依赖构建器生成静态 HTML 页面，带侧栏目录、上一章/下一章导航、C 代码高亮、参考答案折叠块。
- **定位**：URL slug 与内容清单（`manifest.json`）已按将来接入 Django / Flask 后端的路由设计，静态页可无缝平移为未来实验室官网的一个子站。

## 快速开始

### 我是新生 / 只想看内容

1. 双击仓库根目录的 **`打开我.html`**（会自动跳转到站点首页）。
2. 建议按首页的"学习路线表"顺序学习，配合完成作业一、作业二。
3. C 语言开发环境（Dev-C++）与 Markdown 编辑器（Typora / MarkText）安装包**不随仓库分发**，由实验室另行提供。

### 我是维护者 / 想改内容

前提：机器上有 Node.js（`node -v` 能输出版本号即可，**无需 npm install 任何包**）。

1. 用 Typora（或任意编辑器）修改仓库根目录下的 Markdown 源文件。
2. 双击 `tools\build.bat`（或运行 `node tools/build.js`）。
3. 看控制台最后一行：**警告 0 条 = 成功**；有警告会暂停并写入 `web\build-report.txt`。
4. 打开 `打开我.html` 检查效果，满意后 `git commit`（建议提交信息带 `[web]`）。

详细维护手册见 **[`tools/使用与维护.md`](tools/使用与维护.md)**（新增导学案、改主题色、构建器支持的 Markdown "方言"、警告含义等都在里面）。

```
├─ img/                       真源图片

├─ tools/
│  ├─ build.js                转换器 + 站点生成器（Node 标准库，零依赖）
│  ├─ build.bat               双击构建入口
│  ├─ 使用与维护.md            维护手册
│  └─ 行动计划_静态HTML站点.md   设计决策与规划记录
├─ web/                       构建生成物（已 gitignore，每次构建整站重建）
├─ 打开我.html                 生成物，站点入口跳转页

```

## 设计原则

1. **Markdown 是唯一真源**：`web\` 全部为生成物且已 gitignore，手改必丢，天然防呆。
2. **零外部依赖**：构建器只用 Node 标准库，不 npm install、不引 CDN；换机器、断网、三年后都能构建。
3. **无 JS 也能用**：折叠用原生 `<details>`、目录用纯链接；JS 只做增强（复制按钮、打印前展开）。
4. **为后端留接口**：构建同时产出 `web/manifest.json`（每篇的 slug / 类别 / 标题 / 章节树），URL slug 全 ASCII 且与将来路由 `/docs/<slug>/` 一一对应，上线时内链不用改。
5. **方言收敛**：构建器只支持一套刻意收敛的 Markdown 子集，遇到不认识的写法直接报警告并暂停，防止写法膨胀。

## 发布与注意事项

- **发放给学生前**：删除 `_archive\` 与 `bak\`（工作报告与旧稿存档），并确认 `_archive/下一轮工作指令.md` 等内部文件不随包发出。
- 正式发放前务必跑一次**不带参数的全量构建**（`--only` 调试构建会让首页出现"（P1 生成）"灰字样）。
- 所有导学案中的 C 示例代码均经 `gcc -Wall -Wextra -std=c99` 编译验证，文中"输出"为实际运行结果回填。
