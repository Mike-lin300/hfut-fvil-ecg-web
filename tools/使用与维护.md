# tools 使用与维护手册

> 对象：实验室维护者（你）。学生不需要看这份文件。
> 前提：机器上有 Node（`node -v` 能输出版本号即可，无需装任何包）。

## 0. 一张图看懂流程

```
你改 md ──双击 tools\build.bat──> web\ 全站更新 ──git commit──> 历史可回滚
                          └──> web\build-report.txt（有没有问题看它）
```

## 1. 目录里各是什么、能不能手改

| 路径 | 是什么 | 手改？ |
|---|---|---|
| `导学案*.md`、`作业*.md`、`附录一*.md` | **唯一真源** | 只改这里 |
| `附录二_主控代码\ZXH_FlightCtrl.c` | 真源（代码阅读页的来源） | 可以 |
| `img\` | 真源图片 | 可以 |
| `tools\build.js` | 转换器 + 站点生成器（零依赖） | 会 JS 再改 |
| `tools\build.bat` | 双击入口 | 一般不用改 |
| `web\` | **生成物**，每次构建先整体清空再生成 | 不要，手改必丢 |
| `打开我.html` | 生成物（跳转页） | 不要 |
| `bak\`、`_archive\` | 旧稿与工作报告，不发布 | — |

## 2. 日常三步

1. 用 Typora（或任何编辑器）改 md，保存。
2. 双击 `tools\build.bat`。
3. 看控制台最后一行：`警告 0 条` = 成功；有警告会暂停，让你去看 `web\build-report.txt`。

然后 Edge 打开 `打开我.html` 检查效果；满意就 `git commit`（建议提交信息带 `[web]`）。

## 3. 命令行用法

| 命令 | 作用 |
|---|---|
| `node tools\build.js` | 构建全部 14 页 + 首页（**默认**） |
| `node tools\build.js --only=guide-6,hw-1` | 只构建指定页，调试转换器时快 |

注意：用 `--only` 时，首页里没构建的页会显示为灰色"（P1 生成）"字样；**正式发布前务必跑一次不带参数的全量构建**。

## 4. 加一篇新导学（例：导学案9 链表）

1. 在 docs 根目录建 `导学案9_链表.md`：第一行 `# 导学案9 · 链表：……`；抬头用 `> **前置要求**：…` 那套引用块；页脚用 `> <small>作者：…` 那套。
2. 打开 `tools\build.js`，在顶部的 `PAGES` 数组里加一行：
   `{ slug: 'guide-9', file: '导学案9_链表.md', kind: '导学', note: '一句话介绍' },`
   （slug 必须用 ASCII；kind 只能是 导学 / 选读 / 作业 / 附录，侧栏徽章颜色靠它。）
3. 双击 `build.bat`。侧栏、首页路线表、上一章/下一章按钮会**自动**接好，不用改任何模板。

## 5. 改外观

全部在 `build.js` 里的 `CSS` 常量中，常用的几个：

| 想改什么 | 改哪里 |
|---|---|
| 主题色 | `--accent`（现在是实验室蓝 `#1f6feb`） |
| 代码框底色 | `--code-bg`（现在是 `#e9edf2`，比正文框深一档） |
| 侧栏宽度 | `--side-w` |
| 正文行宽 | 搜 `78ch` |
| 代码高亮配色 | `.tk-kw / .tk-str / .tk-com / .tk-num / .tk-pre / .tk-fn` |

改完双击 build.bat 即生效（css 也是生成物）。

## 6. 构建器认识的"方言"（重要）

转换器只认识我们这套 md 子集，**碰到不认识的写法会写进警告并让 build.bat 暂停**——这是故意的，用来守住方言不再膨胀：

- 支持：`#`~`###` 标题；`> ` 引用块（**里面可以再套代码块 / 表格 / 列表**）；GFM 表格；``` 围栏（标 `c` 的会高亮）；有序 / 无序列表（一层，支持缩进子项）；`**加粗**`、`*斜体*`、行内码、链接、图片；`---` 分隔线。
- 不支持：手写 `<details>` 等 HTML、多层嵌套列表、脚注。想用新写法 → 先扩展转换器，别直接在 md 里写。
- 图片：必须放在 `img\` 下、用相对路径 `img/xxx.png`。构建时自动复制到 `web\assets\img\`，页面上**限宽显示**（不会撑破版式），**点击可开原图**（新标签页）。
- 文末 `## X.N 练习参考代码（做完再看）` 下的每个 `### 练习 N 参考代码` 会自动变成折叠块；对应题面自动加"参考代码 ↧"跳转（**没有答案的题不会加**）。

## 7. 警告与退出码

| 报告里的警告 | 意思 | 怎么办 |
|---|---|---|
| 代码围栏未闭合 | ``` 少了配对的那行 | 回 md 补上 |
| 图片缺失 | 路径写错或文件没放进 `img\` | 改路径 / 补文件 |
| 跳答案锚点无目标 | 题面有跳转但文末没有对应答案 | 补答案，或检查附录标题写法 |
| 退出码 1 + 窗口暂停 | 存在以上任一警告 | 修完重跑，直到 `警告 0 条` |

## 8. 与将来官网（Django / Flask）的衔接

`web\manifest.json` 是内容清单：每篇的 slug、类别、标题、一句话介绍、是否已生成、章节树。将来上线时把它当内容库导入，URL 用 `/docs/<slug>/`，与现在的静态页一一对应，**所有内链不用改**。

## 9. 五分钟熟悉练习（建议真做一遍）

1. 把导学案6 里某句话改几个字 → 保存 → build.bat → Edge 刷新，注意顶栏和页脚的"生成时间"变了。
2. 故意删掉某个 ``` 围栏的配对行 → build.bat，看它怎么报错、报告里写什么 → 改回来再构建。
3. `git diff` 看你改了什么；`git add -A && git commit -m "test"` 提交；再 `git checkout -- 文件名` 或 `git revert` 体验回滚。**玩回滚之前先 commit。**
