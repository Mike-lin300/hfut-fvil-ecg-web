## 0. 四条总原则

1. **md 是唯一真源**，`web/` 是生成物（已 gitignore）。任何人手改 `web/` 都会在下次构建时丢失——天然防呆。
2. **无 JS 也要能用**：折叠用原生 `<details>`、目录用纯链接、布局用纯 CSS。JS 只做增强（高亮已是静态生成、复制按钮、打印前展开）。JS 被安全策略禁掉时，站点只是"朴素"，不是"坏掉"。
3. **零外部依赖**：不 npm install、不引 CDN。转换器用 Node 标准库自写（只支持我们这套已收敛的 md 子集）；C 语言高亮自写（约 60 行规则）。换机器、断网、三年后都能构建。
4. **为将来 Django/Flask 留接口**：构建过程先产出 `manifest.json`（每篇的 slug / 标题 / 元数据 / 章节树 / 正文与答案的 HTML 片段），URL slug 全 ASCII 且与将来路由一致；模板集中在一个常量里，可平移成 Django template。

## 1. 输入契约（转换器要支持的 md 构造）

已盘点 13 篇 md + 1 个 .c 附录，用到的构造只有这些：

| 构造 | 出现处 | 转换输出 |
|---|---|---|
| ATX 标题 1~3 级 | 全部 | `<h1~h3>` + 自动 id（用章节编号，如 `6-3`，稳定短小） |
| 抬头信息引用块（`**前置要求**：…`） | 全部导学/作业 | 信息卡 `<dl class="doc-meta">` |
| 段落 / 加粗 / 行内码 / 斜体 / 链接 | 全部 | 标准内联转换 |
| 图片 `![alt](img/…)` | 导学1、作业 | 复制到 `web/assets/img/`，改写相对路径，`loading="lazy"` |
| GFM 表格 | 全部 | `<div class="table-wrap"><table>`（窄屏横滚） |
| 围栏代码 ` ```c ` / ` ``` ` / ` ```bat ` | 全部 | `<pre><code>`；c 做高亮，其余等宽 |
| 引用块（含**块内嵌套围栏/列表/表格**） | 导学1/4/4附加 等 | 递归处理（这是最容易写错的一条） |
| 有序/无序列表（单层，含续行） | 全部 | `<ol>/<ul>` |
| `---` 分隔、页脚 `<small>` 块 | 全部 | `<hr>`；页脚转元数据卡 + 生成时间 + 源文件名 + commit 短哈希 |
| 文末"练习参考代码"附录 | 导学2~8 | 每组 `### 练习 N 参考代码` 包进 `<details>`；并在对应题面自动加"参考代码"跳转锚点 |

不再支持（也绝不再引入）：`<details>` 手写标签、HTML 混排、多层列表、脚注。出现即构建报错，逼着我们保持方言收敛。

## 3. 站点规格（v1）

- **布局**：≥1000px 左侧固定侧栏（全站目录）+ 正文 78ch 行宽；<1000px 侧栏收为文首 `<details>` 目录（无 JS 可用）。
- **页内**：文首一个"本页目录"折叠块（h2 级）。
- **导航**：页脚"上一章 / 下一章"大按钮；首页有全路线表（导学0→8、附加、作业、附录，标注建议周次）。
- **代码块**：深色底（VS Code Dark+ 配色子集）、行号可选、右上角复制按钮（JS 增强）。
- **答案折叠**：文末附录每组答案一个 `<details>`；题面旁"参考代码 ↧"锚点。Edge 原生支持，无需 JS。
- **打印**：`@media print` 隐藏侧栏与按钮；`beforeprint` 事件用 JS 自动展开所有折叠（无 JS 时答案保持折叠，页面顶部打印提示会注明"答案见屏幕版"）——这是 v1 唯一已知限制。
- **视觉**：系统字体栈（正文 "Microsoft YaHei"/"Segoe UI"，代码 Consolas/"Cascadia Code"）；浅色主题先行，暗色放 v2；强调色给两个候选（实验室蓝 #1f6feb / 信号橙 #d97706），原型期你挑。
- **无 JS 降级矩阵**：折叠 ✓ / 目录 ✓ / 跳转 ✓ / 高亮 ✓（静态生成）/ 复制 ✗ / 打印自动展开 ✗。

## 4. 构建与校验

build.js 流程：读篇目清单 → 逐篇转换 → **校验**（围栏配平、图片文件存在、页内锚点存在、交叉引用"导学案N"目标存在、无残留 `<details>`/绝对路径）→ 写 web/ 与 build-report.txt → 有警告则退出码 1。
build.bat：`node tools\build.js`，非 0 退出时 `pause` 显示报告。
约定：改 md 后双击 build.bat；涉及站点的提交信息带 `[web]`。

## 6. 风险与回退

| 风险 | 对策 |
|---|---|
| 转换器漏了某种 md 写法 | 校验报错 + 原型期人工过目；方言已收敛且"不支持即报错" |
| 学生机是 Win7 无 Edge | md + Typora 路线**继续随包保留**，双保险 |
| 本地 JS 被安全策略拦 | 核心功能无 JS 可用（降级矩阵） |
| 改 md 忘重建 | 页脚显示"生成时间 + commit 哈希"，一眼看出旧站 |
| 磁盘损坏 | git 不防物理损坏；建议每季度把仓库推到一个私有 remote（Gitee/GitHub）或拷一份到网盘 |

## 7. 与将来官网（Django/Flask）的衔接

- `manifest.json` 即内容数据库的雏形：slug、标题、元数据、章节树、正文/答案片段齐全，Django 侧写一个 view 读它渲染即可，或逐步把 md 迁进模型。
- URL 规划 `/docs/guide-6/` 与静态 slug 一一对应，上线时零改链。
- 样式与模板集中在 build.js 顶部常量，可平移为 Django template + static css。
- 现阶段**不引入**任何服务端概念，保持纯静态。
