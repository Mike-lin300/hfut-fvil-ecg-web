1.压缩包

压缩包是什么？

压缩包是把一个或多个文件、文件夹按某种格式打包成一个文件，通常还会用压缩算法把体积变小。常见后缀格式有 zip、rar、7z 等，它做到了：

  • 省空间：文本、日志、代码等压缩后体积明显变小。
  • 省带宽、方便传输：一个文件比几百个文件更容易发送。
  • 方便归档：把一堆文件、目录结构打包在一起，不易散落。
  • 可加密、可校验、可分卷：保护隐私、检查损坏、切成多个小包。

解压

Windows 自带资源管理器能打开 ZIP，看起来像文件夹，还能复制、删除、拖入文件，但这是不规范的行为。大多是后台解压到临时目录或内存，不是真的使用原压缩数据上原地改。直接操作压缩包还可能面临，文件编码解码失败风险等问题，所以我们需要先解压，Windows 11自带解压包工具：

右键文件/文件夹->压缩到.zip文件/解压到某目录

Windows 主要内置 ZIP 的轻量支持，RAR、7z 等通常要装 WinRAR、7-Zip、Bandizip 等。

2.文件与格式

文件

文件是计算机中存储在磁盘等介质上、有名字、可被操作系统读写和管理的一组相关数据的集合，可以是文本、图片、程序等。

扩展名

统一规则，计算机才能正确解码、编码处理文件所以需要文件格式。扩展名（后缀）方便人和计算机识别文件格式，如果你的文件如一个word文档后面没有.doc或.docx，可以打开任意文件夹，在查看->显示->文件扩展名处更改设置，像本文档就是一个 Markdown 文档，扩展名本应为.md

特别介绍Markdown

Markdown 是一种用简单符号（如 #、*、-）标记排版的轻量级纯文本格式，那这些符号呢就可以实现文本的加粗、划线、画框等等，写起来像记事本，渲染后像网页（事实上如果你了解过.html网页文件的话，Markdown也支持很多html的标签语法）。

Markdown 在 AI 时代已成为人机协作的“通用文本格式”。它纯文本、语法轻、结构清晰，大模型容易生成和解析，token 成本也低；人类又能直接读写，渲染后还美观，因此成为 AI 时代基础设施级的文档与知识交换格式。我们后续的导学案，可能会继续采用 Markdown 或者 PDF 文档

3.盘符与路径

盘符

Windows 把每一块存储设备（或一个分区）挂在一个字母后面，再加一个冒号，这就是盘符：

  • C 盘：系统盘，Windows 和大部分软件都住在这里。它塞满了电脑会变卡，重装系统时里面的东西还会没，所以别把重要资料堆在 C 盘（注意：桌面、"我的文档"默认也在 C 盘）。
  • D 盘、E 盘……：数据盘，放自己的文件。
  • U 盘、移动硬盘：插上后临时占一个盘符（比如 F:），拔掉就消失。
  • 有些电脑还有一两个几百 MB、平时看不见的分区（恢复分区），别去动它。

打开此电脑就能看到全部盘符。

路径：文件的门牌地址

一个文件在电脑里的完整位置叫路径，从盘符开始，一层层文件夹往下写，用反斜杠 \ 隔开：

D:\HFUT\AircraftLab\recruitment\Guide\导学案0.txt
片段含义
D:在 D 盘
\HFUT\AircraftLab\...\Guide\一层层嵌套的文件夹
导学案0.txt最终那个文件（文件名 = 主文件名 + . + 扩展名）

绝对路径从盘符写起，在哪都指向同一个文件；相对路径从"我现在所在的文件夹"开始写，其中 . 表示当前这一层，.. 表示上一层。

路径里总是不要出现中文和空格。 很多编程工具诞生在国外，遇到中文路径可能直接找不到文件；而空格在命令行里是"分隔参数"的记号，C:\Program Files\xxx 会被当成两个词，必须加引号才行。 所以写代码请单独建一个干净的文件夹，比如 D:\code\c_study\，全用英文、数字、下划线。

几个立刻能用的小技巧

  • 地址栏：在资源管理器顶部的地址栏点一下空白处，整条路径就变成可复制的文字；反过来，把一条路径粘贴进地址栏回车，就能直接跳过去。
  • 复制文件地址：按住 Shift 右键文件/文件夹（Win11 直接右键），选"复制文件地址 / 复制路径"。
  • 在这儿打开命令行：在地址栏里输入 cmd 回车，会打开一个已经"站在当前文件夹"的命令行窗口（导学案1 的命令行部分会用到）。
  • 命令行里 cd 路径 是走进某个文件夹，cd .. 回上一层，cd /d D:\code 连盘符一起切换。

4.编码

计算机眼里只有数字

CPU 和硬盘只认 0 和 1，本质对应两种电平，一个 0 或 1 叫做位。一个字节（byte）= 8 位，能表示 0~255 共 256 种状态。文字、图片、程序，本质上都是一长串字节。

所以想把"你好"存进电脑，必须先约定好：哪个数字代表哪个字。这个约定就叫编码。细分一下：

  • 字符集：一张"字符 ↔ 编号"的对照表，每个字的编号叫码点。
  • 编码：把编号实际存成几个字节、按什么规则存。

平时说话两者常被混称为"编码"，不必纠结。

ASCII：

美国人最早只需要 128 个符号：大小写字母、数字、标点和几个控制符（换行、回车、Tab），一个字节的低 7 位就装下了。

  • 'A' 的编号是 65，'a' 是 97，'0' 是 48。这也是为什么 C 语言里"字符其实就是个小整数"。
  • ASCII 里没有汉字，没有日文，也没有 emoji。于是各国各自扩表，中文早年诞生了 GB2312，后来又产生了 GBK 和 GB18030

GBK 与 UTF-8

编码一个英文字母一个汉字谁在用
ASCII1 字节不支持老系统、底层协议
GBK（中文 Windows 里写的 "ANSI"）1 字节2 字节中文 Windows、老软件、cmd 窗口
UTF-81 字节一般 3 字节互联网、Linux/macOS、VS Code、Git、AI
  • Unicode 是给全世界所有字符统一发编号的字符集；UTF-8 是它最常用的一种存法（英文只占 1 字节，不浪费空间）。
  • 你在 Windows 里看到的 "ANSI"，在简体中文系统上基本就等于 GBK。

乱码

同一串字节，用错字典去解读，就成了乱码。比如"你好"按 UTF-8 存成 6 个字节，被当成 GBK 来读，就显示成"浣犲ソ"这种莫名其妙的东西。

“手持两把锟斤拷，口中急呼烫烫烫”，遇到乱码，第一反应不是"文件坏了"，而是"换个编码打开试试"
